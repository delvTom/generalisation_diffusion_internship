# Sequential Linear Spectral Schedule

This directory studies the optimal affine velocity associated with two
sequential spectral probability paths on CIFAR-10. The experiment is focused
on generation and explicit-Euler integration: one run produces four figures
that can be read without consulting the implementation.

## Mathematical setup

CIFAR-10 images are normalized to `[-1, 1]`, flattened to `D = 3072`, and
expressed in the non-centered PCA coordinates

```text
z = x U,
mu_z = mu U,
Cov(z) = diag(lambda_sq).
```

The covariance itself is centered and uses the population convention `1/N`.
Both paths share the same component-wise signal schedule `beta_k(t)`:

- coupled noise: `alpha_k(t) = 1 - beta_k(t)`;
- isotropic noise: `alpha_k(t) = 1 - t`.

For either path, define

```text
v_k(t) = alpha_k(t)^2 + lambda_sq_k beta_k(t)^2,
s_k(t) = [dot_alpha_k(t) alpha_k(t)
          + lambda_sq_k dot_beta_k(t) beta_k(t)] / v_k(t).
```

The optimal affine velocity and its exact trajectory are

```text
f_k(z,t) = s_k(t) [z_k - beta_k(t) mu_z_k]
           + dot_beta_k(t) mu_z_k,

z_k*(t) = beta_k(t) mu_z_k + sqrt(v_k(t)) z_0,k.
```

For the same initial noise, both paths have the common endpoint

```text
z*(1) = mu_z + sqrt(lambda_sq) * z_0.
```

The paths therefore define different dynamics, not different exact endpoint
generators.

## Euler convention

Every numerical method in the report is uniform explicit Euler on `[0, 1]`:

```text
z_{n+1} = z_n + (1/N) f(z_n, n/N).
```

`N` is both the number of steps and the number of field evaluations. When
`N = mD`, the uniform grid contains every spectral knot and uses exactly `m`
Euler substeps per spectral interval. Thus `N = 2D = 6144` and
`N = 20D = 61440` are still the same uniform-Euler algorithm as `N = 120`.

Because the field is diagonal and affine, Euler itself is a diagonal affine
map:

```text
z_N = a_N * z_0 + b_N.
```

The implementation composes `a_N` and `b_N` tensorially, then applies the map
to all noises. This is exactly equivalent to integrating every sample
separately but makes the cost independent of the MSE or FID sample count.

## Four report figures

The default run writes only these figures under `images/`:

1. `final_samples.png`

   Five matched initial noises are shown for the exact common endpoint, the
   classic-FM Wiener reference with its historical `N = 30` and `N = 120`
   midpoint sampler, and both sequential paths with `N = 120`, `N = 2D`, and
   `N = 20D`. To reproduce the earlier experiments, the visual noise is first
   drawn in pixel space with seed `42`, then transformed as `z0 = epsilon U`
   in row-vector notation. Every method therefore receives the same underlying
   noise sample, and the classic Wiener rows use exactly the legacy pixel-space
   initialization. A column is a samplewise matched comparison, not merely a
   distributional one. Values are clipped only for display.

   The two Wiener rows are visual references only and are deliberately absent
   from `fid_comparison.png`, avoiding two additional 10,000-image FID runs.

2. `final_mse_vs_steps.png`

   For `B = 256` matched noises, it plots

   ```text
   MSE_N(1) = (1 / BD) sum_b ||z_b^Euler,N(1) - z_b*(1)||_2^2
   ```

   over ten numerical budgets from `N = 60` to `N = 20D`. Error bars are one
   Monte-Carlo standard error. Since `U` is orthogonal, this raw spectral MSE
   equals raw pixel-space MSE.

3. `mse_vs_time.png`

   For each path and `N in {120, 2D, 20D}`, it plots

   ```text
   MSE_N(t) = (1 / BD) sum_b ||z_b^Euler,N(t) - z_b*(t)||_2^2.
   ```

   Euler and the exact solution are always compared at the same time `n/N`.
   Long curves are subsampled only when plotted; integration is unchanged.

4. `fid_comparison.png`

   The exact endpoint and the six selected Euler generators are evaluated with
   TorchMetrics' standard torch-fidelity Inception-v3 FID. The default uses
   10,000 generated images and all 50,000 CIFAR-10 training images. Every
   generator receives the same Gaussian noise sequence. Generated tensors are
   mapped to `[0, 1]` and clipped before Inception; clipping fractions are
   recorded in `metrics.json`.

The run also saves:

- `config.yaml`: resolved configuration;
- `metrics.json`: MSE summaries (including Wiener versus the exact Gaussian
  endpoint), FID values, clipping rates, PCA provenance, seeds, and solver
  conventions;
- `tensors/affine_solver_results.pt`: affine endpoint maps for the sequential
  solvers and classic Wiener, per-sample endpoint errors, and the raw time
  curves behind the figures.

No sensitivity, moment-validation, histogram, or component-dynamics figure is
generated by this runner.

## PCA cache

Artem's Wiener cache in `data/models/wiener/cifar10_32` uses denominator
`N - 1`. For the full 50,000-image training split, this experiment reuses its
mean and eigenvectors and converts the eigenvalues exactly:

```text
lambda_sq_population = lambda_sq_artem * 49999 / 50000.
```

The converted cache and its provenance are stored under
`cache/pca_cifar10_population`. The original cache is not modified.

## Running

Activate the repository environment and run the complete CUDA experiment:

```bash
source .venv/bin/activate
python spectral_paths/sequential_linear_schedule/run_affine_experiment.py
```

The first standard FID run may download torch-fidelity's Inception weights.
Real CIFAR-10 sufficient statistics are then cached at the path configured by
`fid.real_statistics_cache`.

Run the three solver figures without FID:

```bash
python spectral_paths/sequential_linear_schedule/run_affine_experiment.py \
  --skip-fid
```

Run a lightweight CPU pilot:

```bash
python spectral_paths/sequential_linear_schedule/run_affine_experiment.py \
  --pilot \
  --output-root /tmp/sequential_affine_pilot \
  experiment.device=cpu \
  dataset.num_workers=0
```

Change the schedule without editing the YAML:

```bash
python spectral_paths/sequential_linear_schedule/run_affine_experiment.py \
  schedule.epsilon_1=0.1
```

## Tests

```bash
python -m unittest discover \
  -s spectral_paths/sequential_linear_schedule/tests \
  -v
```

The tests cover the schedule, affine field, exact trajectory, exact endpoint,
samplewise Euler, tensorially composed Euler maps, empirical MSE identity, and
PCA cache conventions.
